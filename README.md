# 統計學空間直覺模型互動實驗室

以 **3D 幾何體積、物理槓桿與互動動畫** 視覺化期望值、變異數、標準差與二項分佈核心直覺的互動教學網頁。內建 **12 步新手空間直覺引導模式**，從零帶著學習者一步步建立腦中的具體幾何想像。全站採用 **Zero-Build 原生 ES Modules ＋ Import Maps** 架構，可直接推上 GitHub Pages 部署。

## 五大互動教學模組

1. **模組 1：雙珠箱子與幾何塌縮（單次二項分佈）**
   - 精準對齊 $0$ 號珠 $\pi \times \pi \times (1-\pi)$ 與 $1$ 號珠 $(1-\pi) \times (1-\pi) \times \pi$。
   - 採 **方案 A** 同步 `90°` 翻轉塌縮：共享截面 $\pi(1-\pi)$ 平貼於水平面，厚度 `1.00` 沿垂直軸疊合，切換正上方 **2D 正交俯視** 時呈現純粹的面積錯覺。
   - 支援手動拖偏槓桿支點 $a$，觀察 $I(a) = \sigma^2 + (\mu - a)^2$ 的體積膨脹實驗。
2. **模組 2：多珠積木群與開根號降維尺規**
   - 內建實戰數值劇本與自訂珠子編輯器（自動正規化 $\sum P(x)=1$，支援 `lockDataset` 跨模組共享數據）。
   - 「定厚重鑄模具」三階段動畫：偏差方柱壓縮為定厚 `1.00` 扁平色片 $\to$ 拼鑄為 $\sigma \times \sigma$ 正方形薄板 $\to$ 剝離紫羅蘭 1D 尺規貼合數線 $\mu \pm \sigma$。
3. **模組 3：原點暴力建模與美工刀切割（平行軸定理）**
   - **通用多珠四步驟**：原點建柱 $\to$ 十字爆炸拆解（嚴格依 $2\mu d_i$ 正負號區分翠綠正側翼與上浮紫羅蘭幽靈負體積）$\to$ 側翼空中對撞蒸發 $\to$ 金色 $\mu^2$ 底座沿垂直機率刻度尺疊至 `1.00` 後由紅雷射切離，餘下純變異數 $\sigma^2$。
   - **單次二項極簡三步驟**：$0$ 號珠歸零 $\to$ $1\times 1\times \pi$ 放倒 `90°` $\to$ 一刀切去 $\pi^2$ 底座，餘下 $\pi(1-\pi)$。
4. **模組 4：對立引力網**
   - 隱藏平均數 $\mu$，支援於 3D 地板直接拖曳珠子座標。
   - 任兩顆相異珠子間以動態張力光束與雙向微光脈衝呈現 $\frac{1}{2}$ 係數融合；全員同點時張力完全歸零。
5. **模組 5：二項路徑組合與 $n$ 次獨立放大**
   - 上下聯動雙視區：上區提供「撕掉順序標籤」將 $x!$ 條重複排列折疊為 $\binom{n}{x}$ 條路徑，並提供「至少一個 $P(X\ge 1) = 1 - P(0)$」宇宙挖洞與非負整數離散分佈警語；下區 3D 舞台並排 $n$ 塊塌縮長方體對照線性變異數（$\propto n$）與標準差尺規（$\propto \sqrt{n}$）。

## 技術架構（Zero-Build）

- **模組與渲染**：原生 ES Modules + `importmap` 載入 `Three.js` (`0.169.0`，含 `OrbitControls`、`CSS2DRenderer`)、`GSAP` (`3.12.5`)、`KaTeX` (`0.16.11`)。
- **數學驗算引擎**：`src/core/mathEngine.js` 零 DOM/3D 依賴，即時同步計算定義版、捷徑版與對立引力網版變異數，誤差容許 $< 10^{-9}$。
- **核心設計文件**：[formula_logic.txt](./formula_logic.txt)、[ARCHITECTURE.md](./ARCHITECTURE.md)、[Check1.txt](./notes/Check1.txt)。

## 本機預覽

因瀏覽器對原生 ES Modules（`type="module"`）在 `file://` 協議下會有 CORS 限制，請於專案根目錄啟動本機靜態伺服器：

```bash
python -m http.server 8000
```

隨後於瀏覽器開啟 `http://localhost:8000/`。

## GitHub Pages 部署

專案根目錄即為靜態站點入口（`index.html`），所有資源引用與模組 `import` 均嚴格採用 `./` 相對路徑，可直接在 GitHub Repository Settings $\to$ Pages 選擇部署根目錄（`/`）上線。
